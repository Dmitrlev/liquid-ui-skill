# Sizes — element metrics

The numbers are taken from the kit (`likvid-ui`) and the mockups. Spacing between blocks lives in `layout.md`, not here; this file is element sizes and typography. A draft: from screenshots the model proposes values and pins them here.

## Typography

- body text — 1rem
- card/section heading — 1.125rem
- large content (input text, result) — 1.125–1.375rem
- captions, counters, hints — 0.8125–0.875rem
- navbar tab captions (kit) — 0.6rem

## Controls

- touch-target — 44px minimum
- round icon buttons in the header — 40px
- big circles ("History"/"Saved") — 64px
- icons in buttons/tabs — 18–20px, inside a big circle — 24px
- a `NavBarBase` item icon — 1.75rem (kit)

## Component sizes

- `LiquidButton` pill — kit padding `0.875rem 1rem`, text 0.875rem; do not override in a mockup
- `LiquidRadio` — kit default, title 0.875rem
- content widget card — padding `18px 20px`
