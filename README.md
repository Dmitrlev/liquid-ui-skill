# liquid-ui-skill

A ZCode skill that builds UI mockups in Apple Liquid Glass style from the
[`likvid-ui`](https://github.com/Dmitrlev/likvid-ui) component kit.

Triggered when the user asks for «ликвид глаз» / liquid glass layout work.
The workflow lives in `SKILL.md`; the rules are in `references/`:

| File | Purpose |
|---|---|
| `protocol.md` | where files live, how a mockup replaces the previous one safely |
| `kit-rules.md` | kit rules and React style for mockups (`--likvid-*` token contract) |
| `layout.md` | block layout: background, widths, grids, corner-shape law |
| `sizes.md` | typography and control metrics |
| `anatomy.md` | screen patterns: liquid vs regular surfaces |

The skill content is authored in Russian; file names and this README are English.
